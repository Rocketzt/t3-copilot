# data/ — generated data

- `track3.json`: produced by `scripts/build_data.py` from `../Track 3 Data.xlsx`. Do not edit by hand.
- `feedback_seed.json`: the organizers' 3 records from sheet 07 (accept / edit / reject). Never mutated.

All of it is simulated (`模拟`). No personal data may be stored here (RULE011).
