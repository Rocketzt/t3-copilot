# evidence/ — proof of how we worked

- `screenshots/`: real app screenshots used in slides and docs. See
  `screenshots/README.md` for the file → what it shows → checker-dependent mapping, dates,
  sizes/sha256 and the pending post-merge re-captures. `screenshots/before/` keeps the old
  `engine: fixtures` state for before/after.
- `demo_recording_plan.md`: exact 3–4 minute fallback demo script (mapped to
  `EXECUTION_PLAN.md` §9.1), click path, must-be-visible items, speaker lines, shot list and
  manual recording steps (Game Bar / OBS). **No video file exists yet**; the plan states why.
- `ai/`: raw prompts and outputs of AI-assisted jobs (cross-check, research, drafts), saved before anyone edits them.
- `runs/`: history of test runs, if more than the two in `exports/` are kept.
