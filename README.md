# T3 Ops Copilot

**HackSHSID 2026 · Track 3 (Accenture)** — a decision-support assistant for airline staff handling weather and
operational disruptions at eight fictional airports.

> **模拟 / SIMULATED.** Every airport, event, weather value and number in this project is fictional, generated by
> the organizers (`Track 3 Data.xlsx`). The assistant gives decision support only: flight safety, release,
> cancellation, dispatch, maintenance and compensation decisions stay with qualified people, and passenger drafts
> are reviewed by a person before anything is sent.

## What it is

Four parts in one local web app:

1. **Detector — "is this unusual?"** Three comparisons for each airport-month: the airport's own trailing
   12-month average, same-size peers, and the same month last year. Each comparison that lands 5.00 percentage
   points or more below its baseline is one signal; 0–3 signals → normal / watch / unusual / clearly unusual,
   with a confidence value.
2. **Fact sheet → writer → checker.** Python computes the facts and gives every number a source ID
   (`SIM-BASE`, `SIM-WEATHER`, `SIM-SCALE`, `RULE00x`). The default writer is a deterministic offline template
   that turns the fact sheet into the organizer's 17-field advice plus three audience drafts. The checker (see
   status below) blocks untraceable numbers, committed actions, personal data and causal claims.
3. **Exam.** `tests/run_tests.py` drives the same `engine.pipeline` the website uses — no answer bank — through
   the organizer's 15 tests, 5 of our own unseen events and a fabricated-number negative test.
4. **Feedback memory.** Accept / Edit / Reject plus a reason is appended to `data/feedback.jsonl` (never
   overwritten) and quoted the next time a similar event is analysed.

Every page and output carries the `模拟 / SIMULATED` label. The UI is bilingual: **EN / 中文** switch in the
header (translation details in `docs/D08_Reproducibility.md` §7; display only — payloads, checks and the exam are
not affected).

## Who it is for (airline voice)

This is the operations assistant for **our airline's disruption desk** — one fictional Chinese domestic airline.
The detector's priority combines **anomaly with importance to our airline**: a large drop at a high-importance
airport matters more than a similar drop at a small one. Field **f14** is the message to the **airport coordination
team**; field f13 is for our own operations staff and f15 is the passenger draft. Decisions on cancellation,
release, dispatch, maintenance and compensation stay with our airline's qualified staff; the assistant only
prepares evidence and drafts for a human.

## Requirements

- **Python 3.10+** (verified on Windows with Python 3.12.14 and a fresh-clone virtualenv run).
- **The app, engine and tests use the standard library only.** No `pip install`, no network, no API key.
- `requirements.txt` lists **build-time only** packages (`openpyxl`, `pandas`, `Pillow`) for the optional
  workbook/evidence scripts. The app never imports them.
- `data/track3.json` and `data/feedback_seed.json` are **committed**, so a fresh clone runs without rebuilding
  data and without touching `Track 3 Data.xlsx`.

## The five tabs

| Tab | What a judge sees |
|---|---|
| **Assistant** | Choose one of the 5 organizer events (EVT001–EVT005) or type a new event (airport, time window, weather, operations, importance, notes, known/unknown information). Writer selector: offline template (default) or "Demo bad AI" (fabricated number). |
| **Detector** | Stat cards (192 airport-months, 12 own-history flags, 13 any-signal months), a **schematic network priority map** (8 airports, circle size = importance to our airline, colour = verdict, click to open the airport in the Assistant tab, with a ranked table below), a Hailing-vs-Yunchuan monthly completion chart with the same-class peer line and 2025-07/08 highlighted, and a sortable/filterable ranking of all 192 airport-months with verdicts. |

| **Feedback** | Append-only decision log with accept / edit / reject counts; each record keeps the original advice next to the human decision. |
| **About** | What the prototype is, the four parts, data-quality notes (DQ001–DQ004), the 12 rules, counts, limitations and the `模拟` note. |

## Writer modes and keys

- **Default: offline deterministic template.** No network, no model, no API key.
- `.env.example` documents the optional OpenAI-compatible LLM settings (`T3_LLM_BASE_URL`, `T3_LLM_API_KEY`,
  `T3_LLM_MODEL`, writer mode). This build does **not** call a live model (`llm_configured: false`); live AI was
  cut to fit the schedule (see `ROLES.md`). Copy `.env.example` to `.env` only for experiments — `.env` is
  git-ignored. **Never commit a real key.**
- The **bad writer mode** is a demo: it appends a deliberately fabricated "20 points" claim so the checker can
  be shown blocking it — observed today: blocked with check **C02** naming "unwhitelisted number 20 in field
  f05", then the output falls back to the deterministic draft marked for human review.

## Data and limits

- All data is simulated: 8 fictional airports × 24 months = 192 airport-months, 12 rules, 15 official tests,
  5 events, 3 feedback seeds. English airport names are our transliterations.
- Data-quality intents: **DQ001** everything simulated · **DQ002** four missing weather rows (Qinglan 2025-03,
  Gaoyuan 2025-09, Hailing 2025-11, Linjiang 2025-11) · **DQ003** EVT003 has conflicting sources — the honest
  answer is "can't tell" · **DQ004** Hailing 2025-07/08 is a planted anomaly, not a real-world event.
- Monthly airport-level data cannot identify individual flights, crews or gates; weather is background evidence,
  not proof of causation. Never read the app's numbers as real operations data.
- The detector reproduces the organizer workbook exactly (verified against the engine and the live API): 192
  airport-months; 12 own-history flags; 13 any-signal months; signal counts `{0: 179, 1: 11, 2: 1, 3: 1}`;
  Hailing 2025-07 = −15.62 pp vs own average, −5.46 pp vs peers, −11.48 pp vs last year; Yunchuan 2025-07 own
  −6.07 pp but YoY −0.80 pp (seasonal, not unusual).
