## Git workflow

1. Work on your own branch: `ziyu`, `jonathan` or `jason` (already on GitHub). Collaborators: Rocketzt,
   chrochrohoho, JasonXiao7.
2. Commit small and often (every 45–60 min). Mark AI-assisted commits with `Assisted-by: <tool>`, and add an
   **AI:** line to your own log.
3. Before each gate, run `git pull origin main` on your branch and fix any conflicts in your own files.
4. At the gate, Ziyu merges the three branches into `main`.
5. **Shared files** (`docs/project/*.md` outside `log/`, `docs/planning/*`, `ROLES.md`): edit them on `main` only.
   Run `git pull` first, make one small commit, and push immediately.
6. Never commit `.env` or an API key. Never commit personal data.

First-time setup for each person:

```bash
git fetch origin
```

```bash
git switch <your-name>
```
